# Copied HIGGS contracts

These public POD headers are copied from the HIGGS cooperation fork under its GPL-3.0 license. The exact revisions and hashes are recorded in `source-pins.json` and `own-contact-source-pins.json`.

`higgshandpartsnative.h` is used only for native physics-provider attribution of an already borrowed live body. PLANCK sends its address as a comparison key; HIGGS returns copied metadata without dereferencing that address or acquiring engine/broker locks. PLANCK does not receive or retain a HIGGS native body pointer. The regular hand/parts headers are transitive type dependencies, not new implementations of HIGGS behavior.

Official001 remains required and unchanged. Absence of the additive export preserves the existing palm/weapon/held-object classification. Early readiness can return `NOT_READY`; classification retries on later contacts. HIGGS remains loaded for PLANCK's lifetime, as with its existing official001 interface. Never cache a borrowed body key or use this bridge as gameplay lifetime authority.
