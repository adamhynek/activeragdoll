# Copied HIGGS contracts

These public POD headers are copied from the HIGGS cooperation fork under its GPL-3.0 license. The revision and hashes are recorded in `source-pins.json`.

The hand-parts interface in `higgsnativeinterop.h` supplies native physics-provider attribution of an already borrowed live body. PLANCK sends its address as a comparison key; HIGGS returns copied metadata without dereferencing that address or acquiring engine/broker locks. PLANCK does not receive or retain a HIGGS native body pointer. Both native interfaces use the shared data types from `higgsabitypes.h`.

Official001 remains required and unchanged. Absence of the additive export preserves the existing palm/weapon/held-object classification. Early readiness can return `NOT_READY`; classification retries on later contacts. HIGGS remains loaded for PLANCK's lifetime, as with its existing official001 interface. Never cache a borrowed body key or use this bridge as gameplay lifetime authority.

The native hand-parts query requires `HIGGS_HAND_PARTS_NATIVE_ABI_VERSION` 2. A returned owner is an opaque attribution label. Operations on another provider's behalf require its separate authority. PLANCK uses this query only to classify a left or right physical part. Older providers use the existing 001 hand classification.
